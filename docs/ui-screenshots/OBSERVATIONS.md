# Problems noticed while capturing the UI

Found 2026-11-05 while capturing the images in this folder. I looked at about a dozen of the 62 images one by one (the
error, pending, focus and drawer states, the sidebar, the first-run page and a generated answer) and read the code
behind each finding; the rest were produced by the same script and not inspected image by image.

| # | What | Where it shows | Cause (file) | Suggested fix |
|---|---|---|---|---|
| 1 | **Stale, false statement:** "Your data stays in memory. Uploaded files are not saved to a database in this local prototype. Restarting the API clears them." Documents have been saved in Supabase since M6, and this is on the public site. | `02-components/source-health.png` | `apps/web/components/chat/SourceHealth.tsx` | Replace with what is true: stored privately per account, deleted when you remove them (see `docs/data-handling.md`). |

Never render raw HTML: the text can contain untrusted document content. |
